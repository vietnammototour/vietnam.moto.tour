Section 1: Extended Tour Schema

The enriched Tour type that captures all raw doc content

src/types/index.ts — Tour interface
// Bilingual text helper
type LocalizedText = {
  en: string;
  vi: string;
}

interface ItineraryItem {
  time: string;            // "7:00 a.m", "10:15 a.m"
  description: LocalizedText; // what happens at this stop
}

interface ItineraryDay {
  dayLabel: LocalizedText;   // "Day 1: Dalat" or "Itinerary"
  items: ItineraryItem[];
}

interface PricingTier {
  label: LocalizedText;     // "1 Pillion", "Single Rider", "Group of 2"
  price: number;            // USD amount
}

interface Tour {
  // ── Existing fields (unchanged) ──
  id: number;
  title: string;            // short display title (cards)
  imageUrl: string;         // primary card image
  rating: string;
  price: number;            // "from" price for cards
  duration: string;
  distance: string;
  location: string;

  // ── New fields ──
  slug: string;              // "ba-ho-waterfall" — URL identifier
  description: LocalizedText; // marketing description paragraph
  transportation: string;   // "Motorbike", "Private Car A/C", "Motorbike or Private Car"
  groupSize: string;        // "Min 1 Person", "Min 2 Person"
  hotel: string;            // "Pick up & Drop off"
  guided: string;           // "Fully Guided Tour"
  heroImage: string;        // large banner image for detail page
  images: string[];          // gallery (future — empty array for now)
  highlights: LocalizedText[];  // bullet-point highlights
  itinerary: ItineraryDay[];   // structured timeline
  pricing: PricingTier[];      // all price tiers
  included: LocalizedText[];   // what's included list
  excluded: LocalizedText[];   // what's not included list
  paymentDetails: LocalizedText; // deposit & payment terms
  notes: LocalizedText[];      // important notes list
  mealsInfo: LocalizedText;    // meals description
}

Key Design Decisions

  • Existing fields unchanged — TourCard, TourCarousel, all listing components continue to work with zero changes
  • LocalizedText on all display strings — { en, vi } inline bilingual
  • Structural fields stay plain strings — transportation, groupSize, hotel, guided don't need localization (they're short English terms that work in both locales, or can be localized in the component)
  • highlights optional in practice — some tours have them, some don't. Empty array = no highlights section rendered
  • pricing is flat — [{ label, price }] works for both rider-type and group-size pricing
  • images[] ready but empty — no fake data, graceful when empty
