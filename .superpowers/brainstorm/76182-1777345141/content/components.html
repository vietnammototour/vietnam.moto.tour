Routing & Data Flow
Route:  /tours/ba-ho-waterfall
File:   src/pages/tours/[slug].tsx

getStaticPaths()
  → reads toursData from src/data
  → returns { params: { slug } } for each tour
  → generates all 7 pages at build time

getStaticProps({ params, locale })
  → finds tour by params.slug
  → loads locale messages for next-intl
  → returns { props: { tour, messages } }
  → 404 if slug not found

Component
  → receives tour as prop
  → each section component gets its slice of tour data
  → useTranslations() for UI labels (section headings, button text)
  → LocalizedText resolved via locale: tour.description[locale]
